# 어필리에이트 구현 기록

- 추천 URL은 /?ref=<신청 계정의 UUID 코드> 형식이다.
- 30일 HttpOnly 쿠키를 사용한다. 현재 초안은 마지막 링크 방문으로 쿠키가 바뀌며, 가입 이후 회원 연결은 변경되지 않는다. 운영 정책 확인이 필요하다.
- 추천 링크가 유효하면 이메일 가입 시 또는 OAuth 콜백에서 신규 회원에 연결한다. 기존 회원 전환 방지를 위해 DB에서 생성 후 10분 이내 계정만 허용한다.
- 신청, PayPal 수취 이메일 변경, 자기 성과 조회는 /dashboard/affiliates에 있다.
- 확인된 docupia@gmail.com 계정은 모든 신청과 월별 성과를 조회한다.
- 신청은 pending으로 등록한다. 관리자는 개별 승인/거절을 선택할 수 있다. 자동 승인 조건과 수당 계산은 보류한다.
- 현재 지급 기록 화면은 approved 계정에만 표시된다. 수동 지급액, PayPal 거래 번호, 지급 당시 수취 이메일을 기록하며 추천인/월/통화 조합과 거래 번호에 UNIQUE 제약을 둔다.
- 선불 결제는 paypal_payments INSERT 트리거로 반영한다. 월 구독 성공 결제, 환불, capture 환불/취소는 서명 검증된 웹훅으로 기록한다. 실패 결제는 원장에 포함하지 않는다.
- 거래 ID로 재처리를 중복 제거하고, 환불은 원거래와 연결해 차감한다. 늦게 도착한 구독 정보는 조회 시 연결한다.
- 월 경계는 UTC이고 환불은 발생 월에 음수로 기록한다. 이미 지급된 월의 기록을 변경하지 않는다. 차월 환불의 수당 상계 정책은 결정이 필요하다.
- 과거 구독 성공 결제/환불 원본은 기존 시스템에 저장되지 않아 별도 PayPal 대사가 필요하다. 현재 구현은 배포 이후 발생 거래를 처리한다.
- 유료 결제액과 환불을 집계하는 매출 화면이며, 수당률 미정으로 지급 예정 수당을 계산하지 않는다.
- DB migration: supabase/migrations/202611180001_affiliates.sql
- 웹 타입 검사와 기존 36개 테스트 통과. 실제 PayPal 웹훅, DB migration 실행, 브라우저 종단 검증은 미수행.
- 남은 결정: 수당률과 적용 시점, 자동/수동 승인, 쿠키 첫/마지막 추천인, 환불 상계 및 정산 통화/월 기준.


## 확정 운영 정책

- 기본 수당률 10%, 신청 즉시 자동 승인, 가입 전 마지막 추천인 적용.
- 기존 pending 신청은 정책 마이그레이션에서 approved로 전환한다. 거절 상태는 유지한다.
- affiliate_commissions 뷰가 통화별 월 매출에 10%를 적용해 소수 둘째 자리로 반올림한다.
- 지급 기록은 서버에서 계산한 양수 수당을 저장한다. 사용자 입력 지급액은 받지 않는다.
- 환불 발생 월의 음수 수당과 이후 월 상계 정책은 별도 결정이 필요하다.
- 정책 마이그레이션은 202611180002_affiliate_policy.sql이다.

## 마이너스 이월 및 상계

- affiliate_balances에서 통화별로 월 수당 - 지급액의 누적 잔액을 계산한다.
- 음수 잔액은 장부에 유지되며 다음 달의 수당과 합산된다.
- 완료 월의 누적 양수 미지급 잔액만 지급 기록할 수 있다.
- 추천인 행 잠금과 월/통화 UNIQUE 제약으로 동시 중복 정산을 방지한다.
- 후속 월 지급 기록이 있는 이전 월은 정산할 수 없다.
- 예: -10 이월 + 다음 수당 25 = 지급 가능 잔액 15.
- 마이그레이션: 202611180003_affiliate_carryforward.sql

## 최초 실적 100명 영구 보너스

- 첫 양수 추천 매출을 달성한 100명에게 추가 20%p, 총 30%를 영구 적용한다.
- affiliate_founders의 영구 순번은 advisory transaction lock으로 배정하며 100명 제약을 둔다.
- 기존 기록은 첫 매출 발생 시각과 거래 ID 순서로 최초 100명을 선정한다.
- 도입 이후는 매출 원장 기록 순서로 선착순을 확정한다. 늦게 도착한 과거 웹훅이 기존 선정을 교체하지 않는다.
- 환불은 선정 자격을 회수하지 않으며 동일 30%로 수당에서 차감한다.
- 기존 월 수당에도 선정된 계정의 30%를 적용하고 과거 지급액은 차감해 잔액에 반영한다.
- 마이그레이션: 202611180004_affiliate_founders.sql
